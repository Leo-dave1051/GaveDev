# PaintHeist

A 2D top-down museum heist game developed in Java using Java Swing.

## About the Game

PaintHeist is a cooperative museum heist game where players recreate famous paintings, replace the originals with their copies, and escape without getting caught by museum guards.

## Technology

- Java 21
- Java Swing
- Visual Studio Code
- Git and GitHub

## Project Structure

The project will be organized into separate packages for the game engine, states, entities, world, assets, systems, and user interface.

## Development

This repository contains the source code and assets for the PaintHeist game project.

Development is currently in progress.
